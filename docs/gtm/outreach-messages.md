# Outreach messages (Agent A, phase 2)

ShiftPatch is a pre-launch concept. Nothing is built. Nothing here has been sent: these messages are written and ready, not live.

**Format (D-027, D-028).** 20 prospects, as approved in `docs/gtm/outreach-picks.md`. Each gets two pieces:
1. A LinkedIn connection note, 300 characters or fewer including spaces, no link, one cited fact.
2. A first message of about 500 characters, sent once the invite is accepted. It says this is an idea being tested and nothing is built, asks one question, and carries the same link for everyone: https://shiftpatch-concept.pages.dev/go/direct_outreach?c=msg_v1

**Why the messages share a sentence.** The one sentence on how the idea would work is the same, or nearly the same, in every first message. It is the only approved claim (D-010), so it is kept the same on purpose rather than reworded 20 ways. The cited fact and the question are written for each person.

Character counts below include spaces and the sign-off "Gabriel". The link is the same for everyone and carries no per-person tag.

**How to use.**
- Check that the person is still in post before sending. For P17 and P29 this is flagged on the entry itself.
- Every message is signed "Gabriel".
- Do not add anything. Each note cites one fact from that row of `docs/research/prospects.csv`, and the fact is listed under the entry so a reviewer can check it.
- Send the first message only after the invite is accepted. Do not send both at once.
- Pairs at the same organization (NCH, North Florida, Sarasota Memorial, Memorial Healthcare System, Tampa General, Lee Health): send on different days.

**How the idea is described.** Only with the wording from "How it would work" in `src/components/LandingPage.astro`: an open shift goes to nurses on the hospital's own staff and float pool who've said they'd like extra hours, one takes it, and the manager sees who's covering. It is always described conditionally. Phoning around appears only as a question (P29).
